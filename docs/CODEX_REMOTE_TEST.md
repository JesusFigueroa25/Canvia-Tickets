# Prueba de Codex Remote

Codex Remote permite delegar tareas de desarrollo a Codex en un entorno remoto en la nube. Puede investigar errores, preparar cambios y ejecutar comprobaciones con las herramientas disponibles en ese entorno. La documentación oficial describe esta modalidad como Codex Cloud.

Sus principales ventajas son:

- **Continuidad:** las tareas pueden seguir ejecutándose aunque el equipo local esté suspendido.
- **Espacio propio:** cada tarea dispone de su propio espacio de trabajo.
- **Revisión:** permite inspeccionar los archivos modificados y los resultados antes de integrar los cambios.
- **Reutilización:** los entornos publicados permiten aprovechar la misma configuración de repositorios y herramientas en futuras tareas.

Este archivo sirve como prueba documental en la rama `docs/test-codex-remote`; no acredita que se haya ejecutado una tarea remota.

Fuente: [documentación oficial de Codex Cloud](https://learn.chatgpt.com/docs/cloud).
