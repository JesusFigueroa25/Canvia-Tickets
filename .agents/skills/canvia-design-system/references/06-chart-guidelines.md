# Gráficos — guía operativa

**Fuente normativa:** [Gráficos en DESIGN_SYSTEM.md](../../../../docs/DESIGN_SYSTEM.md#gráficos). Consulta esa sección antes de diseñar o revisar; sus valores no se duplican aquí.

Modifica únicamente presentación exterior autorizada. Inspecciona tamaño, contenedor, fullscreen, leyendas HTML, inputs/outputs, proyección y selecciones. No alterar opciones de Chart.js, datalabels, tooltips, series, colores semánticos, cálculos, plugins ni callbacks TS. No añadir peticiones en hijos ni duplicar consultas; conservar agregados de Paralelos y filtro mensual de volume-month. Si una mejora necesita TS, documenta el bloqueo.

Consulta [08 Protección](08-protected-components.md) y [09 QA](09-visual-qa-checklist.md).
