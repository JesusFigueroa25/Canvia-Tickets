# Design Tokens — guía operativa

**Fuente normativa:** [Design Tokens en DESIGN_SYSTEM.md](../../../../docs/DESIGN_SYSTEM.md#design-tokens). Consulta esa sección antes de diseñar o revisar; sus valores no se duplican aquí.

Antes de proponer CSS, comprueba tokens y reglas existentes, cascada, estilos heredados, tema Material y overlays. Usa la escala y colores normativos del documento enlazado, no una copia local. Define ámbito aislado y verifica contraste real; no uses :root/body o defaults de Chart.js como atajo. Los gradientes Emerald y Sunset son referencias derivadas aún pendientes de validación visual. No aplicar a reportes.

Consulta [08 Protección](08-protected-components.md) y [09 QA](09-visual-qa-checklist.md).
